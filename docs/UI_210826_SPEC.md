# Looper66 desktop UI delta — branch `210826`

This branch preserves the approved Looper66 cassette, mobile composition and
runtime behaviour. It changes only the desktop transport proportions and the
desktop digital speed hierarchy.

## Desktop transport

- The order remains `STOP | PLAY | SPEED UP`.
- The complete three-button strip has exactly the cassette-habitacle width.
- `STOP` and `SPEED UP` have identical width and height.
- Each side control occupies 28 percent of the strip width and 88 percent of
  its height.
- `PLAY` occupies 44 percent of the strip width and the full strip height, so it
  is the dominant control.
- The taller strip closes the dead space above the Beat Crate while remaining
  fully below the cassette mechanism.
- At the reference desktop width, the side controls render close to square and
  the remaining gap to the Beat Crate is approximately 20 pixels.
- The powered-off bitmap contains no active lighting; runtime state lighting
  remains CSS-only and follows the resized button crop precisely.

## Digital readout

- The large desktop speed percentage is reduced to a secondary readout size.
- Track name, state and speed remain HTML, never baked into an asset.
- The phone readout and phone transport asset are unchanged.

## Acceptance checks

- The desktop side controls have equal dimensions.
- `PLAY` is wider and taller than both side controls.
- The outer transport edges coincide with the cassette-habitacle edges.
- All desktop controls remain at least 44 by 44 CSS pixels.
- Desktop Speed Up lighting still reflects levels 0 through 5.
- Desktop, tablet and phone render without overflow or console errors.
